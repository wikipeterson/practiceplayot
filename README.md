# PracticePlayOT.com

Website for PracticePlayOT, a pediatric occupational therapy practice in Havertown, PA.

Moving off the Doteasy Website Builder: domain to Namecheap, site to static hosting (GitHub Pages).

## Layout

- `index.html`, `services.html`, `about.html`, `testimonials.html`, `contact.html`, `404.html`: the site (plain HTML, no build step)
- `css/styles.css`: shared styles ("Soft Petal" theme; colors from the logo: brown `#603810`, petal pink, leaf green `#38B048`)
- `assets/img/`: web-optimized images used by the pages
- `assets/images/`: original images pulled from the Doteasy builder (archive)
- `content/site-content.md`: text captured from the old Doteasy site on Nov 3, 2026

The header and footer are repeated in each page; change them in every file.
